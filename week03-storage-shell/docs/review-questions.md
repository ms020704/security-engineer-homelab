# Week03 — 장기 복습 문제

> **권장 공부법:** 질문을 보고 30초 안에 먼저 **말로 답**한 다음 답을 확인한다. 단순 암기보다 명령어의 의미와 실제 출력 근거를 연결한다.

## Chapter 6 개념 복습

1. **Q. 파티션과 파일시스템의 차이?**A. 파티션은 저장장치의 영역, 파일시스템은 파일·디렉터리를 조직하는 구조다.
2. **Q. mount는 무엇인가?**A. 파일시스템을 Linux 디렉터리 트리에 연결해 접근할 수 있도록 한다.
3. **Q. `lsblk`와 `df` 차이는?**A. 장치 계층·파티션 정보 vs 마운트된 파일시스템 사용량.
4. **Q. fstab에 UUID를 쓰는 이유는?**A. `/dev/nvme...`의 장치명이 바뀌어도 같은 파일시스템을 식별하기 위해서다.
5. **Q. LVM의 PV/VG/LV는 각각?**A. PV는 물리 저장공간, VG는 이를 묶은 공간 풀, LV는 그 풀에서 할당된 논리 장치다.
6. **Q. `lvextend` 후 `xfs_growfs`가 필요한 이유는?**A. 블록장치 LV 확장과 XFS 파일시스템 확장은 별개의 단계다.
7. **Q. `-L 7G`와 `-L +2G` 차이는?**A. 최종 크기 지정과 상대 용량 추가다.
8. **Q. Quota는 무엇인가?**A. 사용자/그룹 등이 쓸 수 있는 파일시스템 공간을 제한한다.
9. **Q. Soft와 Hard Limit 차이?**A. Soft는 유예기간이 가능한 경계, Hard는 초과할 수 없는 상한이다.
10. **Q. 디스크에 여유가 있는데도 `Disk quota exceeded`가 가능한가?**A. 가능하다. 사용자별 Hard Limit를 먼저 만났을 수 있다.
11. **Q. RAID 1의 `[UU]`와 `[U_]` 의미는?**A. 두 멤버 정상 vs 한 멤버가 정상 역할을 수행하지 못하는 상태.
12. **Q. RAID 장애 중에 왜 읽고 쓸 수 있었나?**A. 정상 미러 한쪽이 데이터를 제공하기 때문이다.
13. **Q. RAID와 백업은 왜 다른가?**A. RAID는 하드웨어 장애 시 가용성을 보조하고, 백업은 별도 시점의 데이터로 복원한다.
14. **Q. mdadm.conf와 fstab의 차이는?**
    A. RAID 배열 식별/조립 정보 vs 파일시스템의 마운트 위치와 옵션이다.

## Chapter 7 개념 복습

15. **Q. 셸 스크립트를 사용하는 이유는?**A. 반복되는 서버 작업을 동일한 절차로 자동화하기 위해서다.
16. **Q. `#!/bin/bash`와 `chmod +x`의 역할은?**A. 실행 인터프리터 지정과 실행 권한 부여.
17. **Q. `./script.sh`와 `bash script.sh` 차이는?**A. 직접 실행은 실행 비트/Shebang에 의존하며 `bash` 호출은 Bash로 파일을 읽는다.
18. **Q. `$1`, `$2`, `$#`, `$?`는?**A. 첫째·둘째 인자, 인자 개수, 직전 명령 종료 코드.
19. **Q. `${1:-80}`은 무엇인가?**A. 첫 인자가 없거나 빈 값일 때 기본값 80을 사용한다.
20. **Q. `$(...)`와 `$((...))` 차이는?**A. 명령 출력 치환과 산술 계산.
21. **Q. `if`와 `case`는 언제?**A. 참·거짓 분기와 입력 패턴별 여러 분기.
22. **Q. `for`와 `while` 차이는?**A. 목록을 순회하는 반복과 조건이 참인 동안의 반복.
23. **Q. `return`과 `exit` 차이는?**A. 함수에서 반환 vs 셸 스크립트를 종료.
24. **Q. `bash -n` 통과면 기능도 정상인가?**A. 아니다. 문법 검사로 런타임 오류를 발견하지 못할 수 있다.
25. **Q. `>`/`>>`/`2>&1`은?**A. 표준 출력 덮어쓰기/추가하기/표준 오류를 현재 표준 출력의 대상으로 연결하기.
26. **Q. 백업을 성공했다고 판단할 근거는?**A. 파일 생성뿐 아니라 압축 내용 확인, 복원, 원본 대조(`cmp` 종료 코드 0).
27. **Q. `disk abc`의 종료 코드가 2라는 의미는?**A. 스크립트가 잘못된 임계값을 감지하고 비정상 종료 상태 2를 반환했다.
28. **Q. 왜 RAID 자동 마운트를 재부팅 후 검증하나?**
    A. 현재 세션에서 마운트가 되었다는 것과 부팅 시 배열 조립·자동 마운트가 되는 것은 다르기 때문이다.

## 실제 서버에서 복습 테스트 (기존 디스크 파괴 없이)

- [ ] `lsblk -f`, `df -Th`, `findmnt`의 차이를 설명한다.
- [ ] `sudo pvs`, `sudo vgs`, `sudo lvs` 출력에서 LVM 구조를 읽는다.
- [ ] `df -Th /mnt/lvmdata`에서 확장된 XFS 크기를 확인한다.
- [ ] `sudo xfs_quota -x -c 'report -h -u' /mnt/lvmdata`로 Quota 설정을 해석한다.
- [ ] `cat /proc/mdstat`의 `[UU]` 상태와 `mdadm --detail /dev/md0`을 해석한다.
- [ ] 마운트가 없는 경우와 `nofail` 설정의 의미를 설명한다.
- [ ] `bash -n`으로 문법 검사를 해 본다.
- [ ] `if`, `case`, `for`, `while` 각 구문을 짧게 설명한다.
- [ ] 정상 입력과 오류 입력 시 출력, 종료 코드를 비교한다.
- [ ] tar 복원 후 `cmp`, `echo $?`로 일치 여부를 확인한다.

**절대 기존 실습 디스크에 `mkfs`, `fdisk g/w`, `mdadm --create`를 재실행하지 않는다.** 별도 신규 디스크/VM에서만 새로 구축한다.
