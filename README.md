# Security Engineer HomeLab

보안엔지니어 취업 준비를 위해 Linux 서버를 직접 구축·운영·보안하면서 학습한 내용을 기록하는 저장소입니다.

## 진행 방식

매주 하나의 실습 목표를 정하고 아래 과정을 반복합니다.

1. 필요한 개념 학습
2. 직접 구축
3. 서비스 운영
4. 보안 설정 적용
5. 의도적인 장애 발생
6. 원인 분석 및 복구
7. 로그 확인
8. 결과 정리
